# CS Zeus Arena

Браузерний онлайн-шутер від першої особи: мапа de_dust2, вбивство Zeus x27 (одна іскра — один фраг), режими **всі проти всіх**, **1х1**, **2х2**, **3х3**, **4х4**. Сервер на Node.js (WebSocket) — авторитетний для команд/здоров'я/фрагів, рухи клієнт передає сам (просто і достатньо для гри з друзями).

## Запуск локально

```bash
npm install
npm start
```

Відкрий у браузері `http://localhost:3000`. Щоб перевірити мультиплеєр — відкрий ще одну вкладку (або дай посилання другу в тій самій мережі, вказавши свою локальну IP, напр. `http://192.168.0.5:3000`).

## Гра з друзями на РІЗНИХ wifi/мережах

Локально сервер бачать тільки ті, хто в одній мережі з тобою. Щоб грали люди з різних wifi, потрібен сервер, доступний з інтернету. Найпростіші безкоштовні варіанти:

1. **Render.com** (безкоштовно): створи Web Service → підключи цей код (або завантаж як .zip) → Build command `npm install`, Start command `npm start`. Отримаєш публічне посилання типу `https://твоя-гра.onrender.com` — просто кидаєш його друзям.
2. **Railway.app** або **Fly.io** — аналогічно, `npm install && npm start`.
3. **Швидкий тест без деплою**: встанови [ngrok](https://ngrok.com) або `npx localtunnel --port 3000`, запусти `npm start`, тунель дасть тимчасове публічне посилання — підійде перевірити гру за 2 хвилини, але не для постійного сервера.

Коли сервер публічний, у меню гри в полі **«Адреса сервера»** вкажи його адресу (якщо граєш прямо на сторінці, яку роздає сам сервер — поле можна лишити пустим).

## Режими

- **Всі проти всіх** — спільна постійна арена (до 8 гравців), заходиш і одразу в бою.
- **1х1 / 2х2 / 3х3 / 4х4** — командний пошук гри: чекаєш, поки назбирається потрібна кількість гравців, потім старт. Перемога — до заданої кількості фрагів команди.
- **Приватна кімната** — «Створити приватну кімнату» дає код з 5 символів, ти кажеш його другу, він вводить код у полі «Приєднатись за кодом» — граєте тільки ви, незалежно від того, хто ще підключений до сервера.

## Керування

- `WASD` — рух, миша — огляд (клік по екрану вмикає захоплення курсора).
- Ліва кнопка миші — атака Zeus (ближній ураз, миттєве вбивство, невеликий відкат між ударами).

## Що варто знати (чесно про обмеження MVP)

- **Рух клієнт-авторитетний** (сервер довіряє позиції, яку присилає клієнт) — просто і працює чудово для гри з друзями, але теоретично дає простір для читів. Якщо колись захочеш публічний рейтинговий сервер — рух і влучання треба буде перенести повністю на сервер.
- Немає стрибка/гравітації — персонаж "ковзає" по поверхні мапи (підлога/рампи/сходи), через стіни не проходить, але високі ящики не перестрибнути.
- Модель персонажа без анімації ходьби (статична поза) — рухається й повертається плавно, але не "крокує". Додати анімацію легко, якщо матимеш gltf з ходьбою.
- Колізії зі стінами — спрощені (кілька променів навколо гравця), у вузьких коридорах можуть траплятись дрібні застрягання.
